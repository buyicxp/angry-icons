# 愤怒的图标

把 Windows 桌面图标当成弹丸，用弹弓射出去砸同事和老板的桌面覆盖层小游戏。

纯代码 WPF，单文件实现，物理内核是真正的 Box2D 2.0.2（C# 移植 Box2DX）。窗口全屏置顶覆盖在桌面上，按 ESC 立刻退出，**不会移动、删除或修改你桌面上任何一个图标或文件**。

![icon](app2.png)

## 玩法

- 弹弓左侧待发位放着一枚圆形图标徽章，按住鼠标往后拉，松手发射。
- 右侧是办公场景，同事和老板站在显示器、文件纸箱、铁皮柜搭出来的掩体后面。
- 打中同事掉 1 点耐久，老板要 2 点；掩体分玻璃、木头、金属三种材质，硬度依次递增。
- 清空当前关卡的同事和老板，自动进入下一关，共 5 关，难度递增。
- 没有计时也没有失败判定，打不完可以一直拉。

## 弹丸类型

弹药架 5 格，按固定顺序轮转：

| 图标 | 效果 |
| --- | --- |
| 普通圆形徽章 | 标准体重与速度 |
| 红色徽章 | 碰到任何物体立刻引爆，爆炸半径 330px，按距离给 4/2/1 点伤害，能把掩体炸成两段或直接炸没 |
| 巨型徽章 | 体重和冲击力更大，能砸穿两层结构 |

## 操作

| 按键 | 作用 |
| --- | --- |
| 按住鼠标左键拖动 | 拉弹弓，拖得越远初速越大 |
| 松开左键 | 发射 |
| ESC | 立即退出，桌面恢复原样 |

## 系统要求

- Windows 10 / 11
- .NET Framework 4.x（系统自带 WPF 与 `csc.exe`，无需安装 SDK）
- 显示器建议 1920×1080 及以上；界面按屏幕实际像素自适应

## 运行

已经编译好的话，直接用 `csc` 编出来的 exe 运行即可。**必须保证下面三样在同一个目录**：

```
愤怒的图标.exe
Box2DX.dll
sfx\            （可选，见下文音效说明）
```

缺 `Box2DX.dll` 会在启动瞬间报程序集加载失败；缺 `sfx` 则自动退回内置合成音，游戏照常能玩。

## 编译

### 方式一：用系统自带的 csc（无需安装任何 SDK）

仓库里的 `build.ps1` 走的就是这条路。它直接调用

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

并引用同目录下的 WPF 程序集编译。在 PowerShell 里执行：

```powershell
.\build.ps1
```

输出 `DesktopAngry.exe`（文件名是历史遗留，成品可以随意改名）。

### 方式二：Visual Studio

新建一个「WPF 应用 (.NET Framework)」项目，把 `DesktopAngry.cs`、`Phys.cs` 加进去，引用 `Box2DX.dll`，目标框架选 .NET Framework 4.0 或以上，编译即可。入口是 `DesktopAngry.cs` 里的 `Main`，注意项目属性里关掉自动生成的 `App.xaml`，否则会和手写的启动流程冲突。

## 音效

**本仓库不包含任何音频文件。**

早期版本曾使用一批从商业游戏里提取的音效，那些素材有版权，不能随源码分发，因此已全部移除。程序在 `sfx` 目录不存在或找不到对应文件时，会自动使用代码内置的 DSP 合成音，功能完整、只是听感朴素。

想换成自己的音效，在 exe 同级建一个 `sfx` 目录，按 `Sfx` 类里 `Register(...)` 的文件名放入 wav 即可（建议 mono / 16bit / 16000Hz）。只放你有权使用的素材，比如 CC0 音效库或自己录的。

## 目录结构

```
DesktopAngry.cs   主程序：窗口、关卡、渲染、音效、交互
Phys.cs           Box2D 封装：刚体、接触监听、爆炸冲击
build.ps1         csc 编译脚本
Box2DX.dll        Box2D 的 C# 移植（第三方依赖）
app.ico           程序图标
app2.png          图标 256px 原图
```

## 隐私

程序只在本机内存里读取当前的桌面壁纸和图标外观，用来绘制背景与弹丸贴图。**不采集、不记录、不上传任何数据**，不联网，不写注册表，不修改桌面。
